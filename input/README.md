# 발송 템플릿 준비

`input` 바로 아래 폴더 하나가 템플릿 하나입니다. 실제 텍스트와 이미지는 Git에 포함되지 않습니다.

```text
input/
  개업안내/
    message.txt
    01_intro.jpg
    02_details.jpg
  행사안내/
    message.txt
    01_poster.jpg
```

- `message.txt`: UTF-8 텍스트. 제목이 필요하면 첫 줄에 직접 적으세요. 파일 전체의 공백·줄바꿈을 그대로 하나의 MMS로 보냅니다. 별도 subject는 보내지 않습니다.
- 본문은 공백뿐이면 안 되며 EUC-KR로 표현 가능한 문자로 2000바이트 이하여야 합니다. 지원하지 않는 이모지나 너무 긴 본문은 자동 수정하지 않고 차단합니다.
- JPG/JPEG 1~2장: 각각 300KB 이하, 최대 1500×1440. 파일명 순서로 첨부하므로 `01_`, `02_` 접두어를 권장합니다. PNG는 직접 JPEG로 준비하세요.
- 심볼릭 링크·정션으로 외부 파일을 참조하지 마세요. 이름에 제어 문자를 넣지 마세요.

프로젝트 루트의 터미널에서 실행합니다.

```powershell
uv run sens-mms preflight
```

목록에서 번호를 입력하거나 이름을 직접 지정합니다.

```powershell
uv run sens-mms preflight --template 행사안내
```

템플릿 선택과 사전 검증만으로 발송하지 않습니다. `live`에는 같은 템플릿명과 해당 내용에 대한 새 승인 토큰이 필요합니다. 파일을 수정하면 다시 preflight하고 승인받아야 합니다.

템플릿을 바꿔도 기존 결과 이력을 공유합니다. 이미 `SENT`인 번호가 새 발송 대상이 되지는 않습니다.

# SENS `.env` 제한적 로딩 설계

## 목적

실제 SENS MMS 발송 프로그램이 프로젝트 루트의 `.env`에서 자격증명을 로드할 수 있도록 허용하되, 에이전트·셸·테스트·로그가 비밀값을 직접 확인하거나 노출하지 못하도록 기존 안전 경계를 유지한다.

## 선택한 접근

`.env` 접근을 전면 허용하지 않는다. 프로젝트가 승인한 Python 발송 진입점만 `.env`를 읽어 필요한 값을 현재 프로세스 환경에 적재할 수 있다. 에이전트는 해당 Python 프로그램을 실행할 수 있지만 `.env` 파일을 직접 열거나 내용을 출력하는 명령을 실행할 수 없다.

Python 로더가 읽는 키는 다음 다섯 개로 제한한다.

- `NCP_ACCESS_KEY_ID`
- `NCP_SECRET_KEY`
- `NCP_SENS_SERVICE_ID`
- `NCP_SENS_FROM_NUMBER`
- `SENS_CONTENT_TYPE`

`SENS_CONTENT_TYPE`은 이번 비광고성 발송에서 `COMM`이어야 한다. 프로그램은 기존 프로세스 환경변수를 우선하고, 없는 값만 `.env`에서 보충한다.

## 비밀 취급 경계

- `.env` 값은 현재 Python 프로세스 메모리에서만 사용한다.
- 에이전트, 셸 명령, 테스트 코드는 `.env`를 직접 열거나 내용을 출력하지 않는다.
- 프로그램은 키의 존재 여부와 형식만 검증하며 값을 로그에 출력하지 않는다.
- Access Key, Secret Key, 생성된 서명, 인증 헤더 및 전체 API 요청 본문을 소스, 테스트 데이터, 콘솔, 오류, 문서 또는 `result.csv`에 기록하지 않는다.
- 발신번호는 실발송 직전 승인 요약에만 정확한 값으로 표시하고, 그 외 로그와 보고에서는 프로젝트 개인정보 규칙을 따른다.
- 예외와 HTTP 오류는 비밀값 및 수신자 개인정보를 제거한 뒤 보고한다.

## 실행 흐름

1. Python 진입점이 기존 프로세스 환경을 확인한다.
2. 필요한 키가 없을 때만 프로젝트 루트의 `.env`를 내부적으로 파싱한다.
3. 자격증명 값은 출력하지 않고 존재 여부만 검증한다.
4. 드라이런과 사전검증은 실제 SENS POST를 호출하지 않는다.
5. 실제 발송 직전에는 수신 건수, 마스킹된 수신번호 표본, 정확한 발신번호, 정확한 본문, 첨부 파일명과 이미지 검증 결과, `contentType=COMM`을 사용자에게 제시한다.
6. 사용자의 새롭고 명시적인 승인을 받은 실행에서만 Python 프로그램의 실발송 모드를 호출한다.

## 오류 처리

- `.env`가 없거나 필수 키가 없으면 API 호출 전에 안전하게 중단한다.
- `.env` 구문이 잘못되었으면 키 이름과 일반화된 원인만 보고하고 원문이나 값을 출력하지 않는다.
- `SENS_CONTENT_TYPE`이 `COMM`이 아니면 이번 실행을 중단한다.
- 모호한 POST 결과, 조회 실패 및 최종 상태 처리는 루트 `AGENTS.md`의 기존 상태 머신을 그대로 적용한다.

## 테스트 전략

테스트는 임시 환경과 가짜 `.env` 경로를 사용하며 실제 프로젝트 `.env`, 실제 자격증명, 실제 수신번호 및 실제 SENS API를 사용하지 않는다.

- 기존 환경변수가 `.env`보다 우선하는지 검증한다.
- 누락된 키만 `.env`에서 보충되는지 검증한다.
- 필수 키 누락과 잘못된 `SENS_CONTENT_TYPE`이 API 호출 전에 차단되는지 검증한다.
- 로그와 예외에 비밀값이 포함되지 않는지 검증한다.
- 드라이런에서 네트워크 호출이 발생하지 않는지 검증한다.

## 정책 변경 범위

루트 `AGENTS.md`에서 `.env` 절대 금지 문구를 다음 의미로 교체한다.

> 프로젝트가 승인한 Python 발송 프로그램은 자격증명을 프로세스 메모리에 적재하기 위한 목적으로만 프로젝트 루트의 `.env`를 읽을 수 있다. 에이전트·셸·테스트는 `.env`를 직접 열거나 내용을 출력할 수 없고, 로더는 값의 존재 여부만 검증하며 비밀값을 로그·오류·결과 파일에 기록하지 않는다.

그 외 실발송 승인, 개인정보, 상태 조정, 재시도 및 결과 저장 규칙은 변경하지 않는다.

## 완료 조건

- `AGENTS.md`가 승인된 제한적 예외와 금지 범위를 명확하게 구분한다.
- Python 구현과 테스트가 `.env` 값의 비노출 및 환경변수 우선순위를 검증한다.
- 실제 발송 승인 절차는 기존보다 완화되지 않는다.
- 에이전트가 `.env` 내용을 직접 조회하지 않고 전체 워크플로우를 실행할 수 있다.
